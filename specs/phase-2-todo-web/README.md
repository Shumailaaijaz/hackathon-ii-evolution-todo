# Phase 2: Todo Web Application

## Overview
This folder contains specifications for Phase 2 of the hackathon project - transforming the console Todo app into a full-stack web application.

## Phase 2 Goals
- Web-based UI (Next.js with React)
- RESTful API (FastAPI)
- PostgreSQL persistence (Neon DB)
- Docker containerization
- Production deployment (Vercel + Railway)

## Directory Structure

### `/features/`
Feature-specific specifications. Each feature gets its own markdown file.
- User stories
- Acceptance criteria
- Business rules
- Edge cases

### `/api/`
API endpoint specifications and contracts.
- REST API design
- Request/response schemas
- Status codes
- Error handling

### `/database/`
Database schema and data model specifications.
- Entity relationships
- Table schemas
- Indexes and constraints
- Migration strategies

### `/ui/`
User interface and UX specifications.
- Component hierarchy
- User flows
- Wireframes/mockups
- Accessibility requirements

## Core Files
- `spec.md` - Main feature specification (generated by `/sp.specify`)
- `plan.md` - Technical architecture plan (generated by `/sp.plan`)
- `tasks.md` - Implementation task breakdown (generated by `/sp.tasks`)

## SpecKit Plus Commands
Use these commands to generate specifications:

```bash
# Create main specification
/sp.specify

# Generate architecture plan
/sp.plan

# Break down into tasks
/sp.tasks

# Create ADR for architectural decisions
/sp.adr <decision-title>

# Generate checklist
/sp.checklist
```

## Technology Stack
- **Frontend**: Next.js 14+, TypeScript, Tailwind CSS, SWR
- **Backend**: FastAPI, Python 3.11+, SQLModel, Pydantic
- **Database**: PostgreSQL (Neon)
- **Deployment**: Vercel (frontend), Railway (backend)
- **Testing**: Playwright (E2E), Pytest (API), Jest (unit)

## Phase 1 → Phase 2 Evolution
This phase builds upon Phase 1 (console app) by:
1. Adding web frontend (Next.js)
2. Exposing REST API (FastAPI)
3. Adding database persistence (PostgreSQL)
4. Containerizing services (Docker)
5. Deploying to production (Vercel + Railway)
